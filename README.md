# Dyslexia Detection from Eye-Tracking Data

Проект посвящён анализу данных айтрекинга при чтении и построению моделей для классификации детей с дислексией и без неё. Основная идея работы — использовать не только классические статистические признаки фиксаций и саккад, но и графовое представление процесса чтения.

## Описание задачи

Дислексия может проявляться в особенностях чтения: более длительных фиксациях, большем числе регрессий, менее регулярных движениях взгляда. В проекте исследуется, можно ли по данным айтрекинга автоматически выделять такие паттерны и использовать их для диагностики.

Цель проекта — сравнить несколько подходов к классификации:

* классические ML-модели на агрегированных признаках;
* модели для последовательностей фиксаций;
* графовые нейросетевые модели, учитывающие структуру переходов взгляда между словами.

## Данные

В работе используются данные айтрекинга детей при чтении предложений.

Основные типы данных:

* координаты фиксаций;
* длительность фиксаций;
* переходы взгляда между словами;
* признаки регрессий;
* социально-демографические признаки;
* метка класса: наличие или отсутствие дислексии.

Данные преобразуются как в табличный формат с агрегированными признаками, так и в последовательности/графы для нейросетевых моделей.

## Использованные подходы

### Baseline

В качестве baseline используются агрегированные признаки по фиксациям и саккадам:

* количество фиксаций;
* суммарная и средняя длительность фиксаций;
* амплитуда саккад;
* количество и доля регрессий;
* регулярность чтения;
* время чтения на слово.

На этих признаках обучаются классические модели машинного обучения.

### Transformer

Фиксации рассматриваются как временная последовательность. Для каждой фиксации используются признаки координат, длительности, амплитуды движения, направления и регрессии. Transformer encoder позволяет учитывать контекст и порядок движений взгляда.

### GINE

Процесс чтения моделируется как граф:

* узлы — слова в предложении;
* признаки узлов — статистики фиксаций на словах;
* рёбра — переходы взгляда между словами;
* признаки рёбер — длина перехода, направление, наличие регрессии.

Для обработки графов используется GINEConv, учитывающий признаки рёбер.

### GAT

GAT-модель расширяет графовый подход за счёт механизма внимания. Она позволяет учитывать важность разных переходов взгляда и объединять графовые признаки с глобальными характеристиками ребёнка.

## Оценка качества

Для оценки моделей используются метрики:

* ROC-AUC;
* balanced accuracy;
* macro F1;
* recall для класса дислексии;
* specificity.

Для более устойчивой оценки применялась repeated cross-validation: 3 запуска 5-fold CV, то есть 15 fold-level результатов. Для попарного сравнения моделей использовался Wilcoxon signed-rank test с поправкой Benjamini–Hochberg.

## Основной результат

Лучшие результаты показала графовая модель GAT с добавлением социально-демографических признаков. Она дала наиболее высокие значения ROC-AUC, balanced accuracy и F1 среди рассмотренных моделей.

Это показывает, что графовое представление процесса чтения может быть полезным для анализа айтрекинга и выявления паттернов, связанных с дислексией.
