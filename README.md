# Monte Carlo Evaluation for Dyslexia Classification

Проект посвящён классификации дислексии по eye-tracking данным.
Цель работы — проверить, можно ли по характеристикам движения глаз отличать участников с дислексией от контрольной группы, а также оценить устойчивость результатов с помощью Monte Carlo-подходов.

## Данные

В работе используются данные eye-tracking экспериментов, где участники читали предложения, а затем для них строились признаки на уровне фиксаций, слов, предложений и субъекта.

Используемые группы признаков:

* **Eye-tracking признаки**: длительности фиксаций, общее время чтения, время на слово, саккады, регрессии, повторные фиксации;
* **Социально-демографические признаки**: возраст, пол, класс, IQ;
* **Графовые признаки**: структура переходов взгляда между словами или фиксациями.

## Модели

В проекте сравниваются несколько подходов:

* **CatBoost** — модель на табличных агрегированных признаках;
* **Transformer** — модель для последовательностей фиксаций;
* **GINE** — графовая нейронная сеть на графах слов;
* **GAT** — графовая attention-модель на графах фиксаций.

## Ablation study

Для проверки вклада разных групп признаков был проведён ablation study: модели обучались отдельно на eye-tracking признаках, отдельно на социально-демографических признаках и на их объединении.

Результаты для CatBoost:

| Модель              | Признаки                  |    AUC |
| ------------------- | ------------------------- | -----: |
| CatBoost demo only  | Age, Sex, IQ, Grade       | ~0.641 |
| CatBoost eye only   | eye-tracking признаки     | ~0.879 |
| CatBoost eye + demo | eye-tracking + демография | ~0.905 |

Вывод: основную предсказательную силу дают именно eye-tracking признаки. Демографические признаки сами по себе дают заметно более слабое качество, но немного улучшают результат при добавлении к eye-tracking данным.

## Основные результаты моделей

По repeated cross-validation были получены следующие результаты:

| Модель               |           AUC |
| -------------------- | ------------: |
| CatBoost demo only   | 0.641 ± 0.056 |
| Transformer eye only | 0.761 ± 0.076 |
| GINE eye only        | 0.826 ± 0.057 |
| CatBoost eye only    | 0.879 ± 0.041 |
| CatBoost eye + demo  | 0.905 ± 0.057 |
| GAT eye only         | 0.918 ± 0.045 |
| GAT eye + socdem     | 0.943 ± 0.032 |

Лучший средний результат показала модель **GAT eye + socdem** с AUC около **0.943**.
При этом **CatBoost eye + demo** также показал высокий и устойчивый результат, оставаясь сильной табличной baseline-моделью.

## Monte Carlo-подходы

В проекте используются несколько Monte Carlo-подходов для проверки устойчивости результатов.

### 1. Permutation test

Permutation test используется для проверки, не возникает ли высокое качество случайно.

Идея теста:

1. Обучить модель на настоящих метках и получить `AUC_real`;
2. Несколько раз случайно перемешать метки классов;
3. Каждый раз заново обучить модель и получить `AUC_perm`;
4. Сравнить настоящий AUC с распределением AUC на случайных метках.

Если модель действительно находит связь между eye-tracking признаками и дислексией, то на настоящих метках AUC должен быть значительно выше, чем на перемешанных.

Результаты permutation test:

| Модель                | Реальный AUC | AUC на перемешанных метках |
| --------------------- | -----------: | -------------------------: |
| CatBoost all-features |       ~0.890 |              0.500 ± 0.047 |
| GINE eye only         |       ~0.826 |              0.481 ± 0.032 |
| GAT eye only          |       ~0.918 |              0.474 ± 0.071 |

После перемешивания меток качество падает примерно к случайному уровню `AUC ≈ 0.5`.
Это показывает, что модели не просто запоминают шум или артефакты разбиения, а используют реальную связь между признаками и меткой.

Для оценки значимости можно использовать эмпирическое p-value:

```text
p = (1 + #AUC_perm >= AUC_real) / (1 + N)
```

где `N` — число перестановок, а `#AUC_perm >= AUC_real` — количество случаев, когда качество на случайных метках оказалось не хуже настоящего.

### 2. Repeated cross-validation

Для оценки устойчивости качества используется repeated CV: кросс-валидация повторяется несколько раз с разными random seed.

В ноутбуке используется схема:

```text
3 random seed × 5 folds = 15 оценок качества
```

Это позволяет оценить не только среднее качество модели, но и разброс метрик между разными случайными разбиениями.

### 3. Wilcoxon signed-rank test

Для сравнения моделей используется парный непараметрический тест Вилкоксона.
Он применяется к fold-level метрикам и проверяет, является ли разница между двумя моделями систематической.

На одном 5-fold CV статистическая мощность слишком мала: даже если одна модель лучше другой на всех 5 фолдах, минимальное двухстороннее p-value равно `0.0625`. Поэтому для более устойчивого сравнения используется repeated CV с 15 оценками.

Некоторые результаты сравнения по AUC:

| Сравнение                               | Результат                          |
| --------------------------------------- | ---------------------------------- |
| GAT eye + socdem лучше GINE             | значимо                            |
| GAT eye only лучше GINE                 | значимо                            |
| GAT eye + socdem лучше Transformer      | значимо                            |
| CatBoost eye + demo лучше Transformer   | значимо                            |
| GAT eye + socdem лучше GAT eye only     | значимо по AUC                     |
| GAT eye + socdem vs CatBoost eye + demo | различие незначимо после коррекции |

Таким образом, GAT eye + socdem имеет лучший средний AUC, но его преимущество над CatBoost eye + demo нельзя считать статистически уверенным после коррекции.

## Интерпретация признаков

Для CatBoost была проведена интерпретация с помощью SHAP. Наиболее важными признаками оказались:

* `time_per_word_mean`;
* `total_duration_mean`;
* `mean_saccade_amp_min`;
* `mean_fix_duration_mean`;
* `std_fix_duration_std`;
* `Age`;
* `time_per_word_std`;
* `time_per_word_max`;
* `total_duration_std`;
* `mean_fix_duration_min`;
* `mean_saccade_amp_mean`;
* `Grade`.

Это показывает, что модель в первую очередь опирается на скорость чтения, длительности фиксаций, общее время чтения и характеристики саккад. Демографические признаки присутствуют среди важных, но не являются основным источником качества.

## Вывод

Результаты показывают, что eye-tracking данные содержат полезный сигнал для классификации дислексии.
Модели, использующие признаки движения глаз, значительно превосходят модели, обученные только на социально-демографических данных.

Monte Carlo-подходы подтверждают устойчивость результата:

* permutation test показывает, что при случайных метках качество падает к `AUC ≈ 0.5`;
* repeated CV показывает стабильность качества на разных разбиениях;
* Wilcoxon test позволяет сравнить модели по fold-level результатам.

Лучшей моделью по среднему качеству стала **GAT eye + socdem**, однако **CatBoost eye + demo** также является сильным и интерпретируемым решением.
